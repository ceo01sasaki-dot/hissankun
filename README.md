# ひっ算おたすけ君

ささっきー制作。四則演算を方眼紙で一桁ずつ練習する、日本語のWebアプリです。参照サイトの画面構成と操作を参考に、キャラクターと効果音を新しく制作しています。外部の画像・音声・APIは使いません。

## 起動

Node.js 20以降が必要です。外部パッケージのインストールは不要です。

```sh
cd /workspace/hissankun
npm run dev
```

ポートは3000です。変更する場合は `PORT=3001 npm run dev` を使います。

## 使い方

- テンキーまたはキーボードで式を入力して「けってい」。
- 赤い枠に、吹き出しで尋ねられた計算の答えを入力します。例：28＋17の最初の入力は、8＋7の **15** です。
- 繰り上がり・繰り下がりや、かけ算の部分積、わり算の「たてる・かける・ひく・おろす」を順に表示します。
- わり算は説明を「つぎへ」で進め、商・積・差・下ろす数字を順番に入力します。商が0のときは余分な掛け算・引き算を省き、位を保って次の数字を下ろします。
- 「アシスト」で考え方や答えを確認できます。かけ算・わり算では、該当する九九と前後の式、繰り上がりの加算を表示します。「もどす」「すすむ」で操作を取り消し・再実行できます。
- 間違えた答えは毎回消去し、新しく入力できます。削除ボタンは押した瞬間に1文字消し、長押しで連続削除します。カーソルは縦線です。
- 設定では繰り上がり・繰り下がりの記入位置と効果音を変更できます。
- 式・進行状態・設定は同じブラウザーのlocalStorageに自動保存します。クラウド同期はありません。
- Enterで決定、Backspaceで一文字削除。掛け算は `*` または `x`、割り算は `/`。

画面全体を基本90％に縮小し、表示領域の幅・高さに合わせて全体が収まるよう自動調整します。方眼紙は16列×12行です。

整数のみ。最初の数は4桁、後の数は加減算4桁・乗算3桁・除算2桁まで。負になる引き算と0除算は受け付けません。割り算は整数商とあまりを表示します。

## 検証

```sh
npm run check
npm test
```

四則演算、繰り上がり、0をまたぐ繰り下がり、部分積、あまり、設定別表示位置、九九アシストの対象、音声の繰り返し再生と中断からの復帰を検証します。15件のテストがあります。

## 構成

`arithmetic.js` が学習手順を生成し、`app.js` がSVG方眼紙と操作・保存、`sound.js` がWeb Audio効果音と音声コンテキストの復帰を担当します。`server.js` は外部依存のない開発用静的サーバーです。公開先へのデプロイは別途必要です。

## 単独HTMLの更新

Python 3が使える環境で `npm run build:html` を実行すると、同じソースから `downloads/hissankun.html` とZIPを生成します。外部通信不要で動くHTML版です。Web版を修正した際は、このコマンドでHTML版も更新してください。
